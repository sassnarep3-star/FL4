Rules

IDRuleWhy
DS-1A depth record is a slot GROUP (club, unit, position, displayed rank label), not a single starter. A group may list zero, one or several players.Three receivers at rank 1 and three inside linebackers at rank 1 are real displayed states. Taking column 1 as 'the starter' would name a starter the club never named.
DS-2A shared slot (two or more players in one displayed cell) is stored as one slot with a players list of length >1, flagged shared=true.Seahawks' WR1 cell lists two names. Splitting or ranking them would invent an order.
DS-3An empty displayed slot is stored as a slot with players=[] and empty=true. It is never dropped.A dropped empty slot is indistinguishable from a missing row, which the drift alarm must catch separately.
DS-4Depth order is taken only from the displayed rank position. Jersey number, experience, salary, roster position label or alphabetical order never sets rank.Brief: reject deriving order from jersey number, experience or salary. Jersey numbers are stripped from names but kept in raw_cell.
DS-5Every player cell is stored twice: raw_cell (exact text as published) and name (raw_cell with a leading jersey number removed). Name normalisation is the only transformation allowed.Packers prepend jersey numbers; stripping them recovers names without changing meaning.
DS-6Each slot records source_url, publisher_label (verbatim wording of any 'unofficial' or 'official' label), authority (see DS-7), capture_utc and page_sha256.Every row must trace to a page the owner can open.
DS-7authority is one of: official_club_labelled (publisher calls it official), publisher_labels_unofficial, club_news_says_unofficial, no_label_seen, unverified. Only official_club_labelled may be used to open the route gate DEPTH-ROUTE-A.Patriots and Packers label their depth charts unofficial on the page. Opening the gate on such charts is an owner decision (see flag).
DS-8Each slot is versioned against the most recent official roster or transaction event that touches any listed player (roster_event_ref). A slot whose versioning event is newer than its capture is stale and must be re-captured before use.Brief: depth, availability and lineup evidence must be versioned against the last official roster event, not trusted as durable.
DS-9A listed player who is injured per the official report is shown as listed. The record does not reassign the slot. Any replacement claim requires the club's own displayed order at capture, not inference from the injury row.Injury status is not an active or participation status, and a depth row alone does not name a replacement.
DS-10Route (b), depth derived from official snap counts, is not implemented here. It is owned by session e9d38f97 (task U8).Avoids two sessions building the same source.
DS-11Starter, backup and depth-tier labels are NOT assigned by this model. A tier label can be attached only when a source explicitly states a rank for that slot.The brief rejects depth inferred from roster attributes.
