Standing rejections

These are recorded so the shortcut cannot be re-proposed during a schedule crunch. Depth order is never derived from jersey number, experience or salary — each is a proxy for something other than the club's current intent, and each is wrong in the direction that matters most.
#RejectedWhyStatus
REJ-1Deriving depth order from jersey numberJersey number correlates with nothing that determines who plays. It would produce a confident, wrong ordering on every club that renumbered a free-agent signing.standing rejection
REJ-2Deriving depth order from experienceExperience is a proxy for past availability, not for the club's current intent. Rookies start; veterans sit.standing rejection
REJ-3Deriving depth order from salarySalary is a proxy for past negotiation, not for this week's game plan, and it is wrong in the direction that matters most when a cheap replacement has already taken the job.standing rejection
REJ-4Inferring a replacement from the injury reportThe official report has no replacement field. Any name attached to an absence would be a guess presented as a fact.standing rejection

Slot model

A depth slot is a group of players at one rank, not a single starter. A slot may hold several players and may be empty. Several position slots across the league list more than one player at rank 1 - three receivers, three inside linebackers. Treating column 1 as 'the starter' fabricates a starter the club never named.

  • Shared slot — Two or more players listed at the same rank for the same slot. Stored as a list; the render shows both and flags the slot as shared. It must never be silently reduced to one name.
  • Empty slot — A slot the club publishes with no player in it. Stored with an explicit flag, so an empty slot is distinguishable from a slot we failed to capture.
  • Raw string — The published string is stored verbatim next to the parsed fields, so a parser change can be replayed against the original text. This is what recovers clubs whose pages prepend jersey numbers.

Snap-count proxy

Where a club's depth chart is unavailable, snap counts are the starter proxy - playing time, not jersey order. Source: https://www.nfl.com/games/49ers-at-cowboys-2026-reg-10 (L-S06). Official Game Book PDFs are published per game on the official game centre; 12 of the 14 week 10 fixtures publish one. None has been parsed.

Threshold: — The threshold defines the label. Setting it after seeing who it labels is fitting the definition to the answer. It must be set before the first transcription (Q-DEPTH-02).

Staleness check

Flag any depth row that is older than the last official roster event affecting that club's unit. Status: Not running. 0 checks performed. Roster turnover redefines depth for weeks. A depth row that predates a trade or an injured-reserve move is worse than no row, because it looks current.

Announced-starter field

An announced-starter field records a link to an official dated announcement of a starter change. It is never filled by inference and never used to imply a replacement. This is deliberately a different field from 'replacement'. A club announcing a new starting quarterback is an official fact; who that pushes to second string is not published and is not inferred.
