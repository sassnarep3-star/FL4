Joint-evidence gate — currently closed

A combo may be ranked only when (a) a directly validated joint probability exists for that specific combination, measured on settled data with n published, and (b) the operator's void and push rules for that combination are on file.

Prohibited: Multiplying marginal probabilities. Under dependence it is invalid, and in same-game parlays dependence is the whole problem. A product of marginals is not a conservative estimate; it is a different quantity. Publishing it would produce a ranking that rewards the modelling error the gate exists to prevent.

Status: Closed. 0 combos are rankable.

Ranking

Rank key: Benchmark-relative Brier skill score, with a game-cluster lower bound used as the ranking statistic and a multiplicity adjustment for the number of strategies tried.

  • Not win rate — Win rate cannot separate a good process from a good run at any realistic sample size, and it ignores the price taken. Two strategies with identical win rates can have opposite expected value.
  • Not ROI — Season-long ROI is the ranked metric this project explicitly rejects. Short-run ROI is dominated by variance and by stake size, so ranking on it selects for luck and for bold staking.
  • Uncertainty — Every published skill score carries an interval from a bootstrap clustered by game, so bets on the same game do not pretend to be independent observations.
  • Multiplicity — The adjustment uses a journal of all variants tried, including the failed ones. A leaderboard that only sees survivors measures the author's persistence, not the strategy's skill.

Display-only columns, which cannot move the rank: win_rate, roi, stake_size, number_of_bets. These columns are shown for context and cannot move the rank, which is how a lucky staking run is prevented from masking a bad signal.

Signal vs staking

Signal is scored and ranked. Staking is recorded and displayed. The two never mix in the rank key. A strategy with a mediocre signal and an aggressive staking schedule can post the best return in any short sample. Ranking signal separately means the leaderboard answers 'is this a good forecast', not 'did this get lucky with size'. Enforcement: The builder rejects any ranking expression containing a stake field.

Two-stage qualification

Stage 1 — Proper-score qualification

Decide whether the strategy forecasts better than the benchmark at all, before any money concept is introduced. Runnable without prices: True

Entry test
Pre-registration recorded with a commit hash before the evaluation window opens
Chronological evaluation only; no fold trains on a later date
Benchmark-relative Brier skill above the qualification bar, with the game-cluster lower bound above zero
Input-perturbation robustness: the skill survives perturbing each input within its measurement error
No-lookahead timestamp rule: every input timestamp is strictly earlier than the forecast timestamp, which is strictly earlier than kickoff
Sample floor met, counted in settled bets across distinct games

Stage 2 — Prospective CLV and ROI escrow

Confirm the qualified skill converts into beating the closing line, prospectively, on bets that were recorded before kickoff. Runnable without prices: False — blocked by Q-PRICE-01

Entry test
Stage 1 passed, with the result and its interval published
A market price exists for every bet scored (Q-PRICE-01)
Closing-line value measured against the stored closing price, per bet, with n published
A prospective window agreed before the window opens; the window's bets are escrowed, not selected afterwards

Control baselines

Every leaderboard run, in every division, includes the two controls below. A strategy must beat the relevant control to be ranked at all. CTL-FAV needs a market line, so it becomes runnable at the same time as stage 2 (Q-PRICE-01). CTL-RAND is runnable now but is not informative without prices to score against.

#ControlWhat it isPurpose
CTL-RANDRandom picksA coin-flip selection over the same markets in the same window, run with the same number of bets.Establishes what pure chance looks like in this specific window and sample size.
CTL-FAVFavourites onlyAlways take the market favourite, using the market line as the favourite's identity, run over the same markets.Beating 'always back the favourite' is a much higher bar than beating zero, and it is the bar that actually matters.

Demotion gate

A live strategy is sent back to paper automatically when either trigger fires. Neither requires a human to notice.

#TriggerTestThreshold
DEM-1Closing-line value decayTrailing CLV over the agreed window falls below the demotion floor, with the game-cluster upper bound also below the floor.
DEM-2Calibration breakThe forecast probabilities and the observed outcomes diverge beyond the calibration tolerance on the trailing window, judged by a proper score rather than by win rate.

The strategy returns to paper, the demotion is logged with the window and the test that fired, and it may only return after a new pre-registration. A demoted strategy is never silently re-promoted when the number recovers.
