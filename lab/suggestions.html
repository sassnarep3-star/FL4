Suggestions

A decision board, not a work log. Nothing here is approved until you approve it; silence never approves.

Decision board, not a work log. Each suggestion states the problem, the candidate paths with their cost and risk, the recommended path and what it depends on. The 'status' field is the control: nothing below is approved until the owner sets it. Silence never approves. Selection controls on the rendered page are stored in the browser only - they change no code and trigger no capture.

How to review this board

  1. Read the problem and the options for a suggestion.
  2. Choose one option, or write your own in the free-text field.
  3. Record the choice locally with the Save button so it survives a reload.
  4. To make it binding, set status for that row in data/lab/suggestions.json to approved and name the approver. Only that edit changes what the project will do.
