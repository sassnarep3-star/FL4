How to read this page

Each row separates what we already know (with the source that says so) from what is not known, then names the cheapest path to the answer and the fallback if the answer never comes. That last column matters: an unanswered question with no default is a project that silently stops, so every question here carries one.

The 'known' text is written from the sources actually read in this build, not from general familiarity with the league. Where a claim could not be traced to an official page it is written as unverified and mirrored on the Flagged page.
